# 谁是华尔街之狼 🐺

伦、镭、健、超的四人友谊赛。纯静态网页，无后台、无账号登录、无数据库、无外部字体或 CDN。

## 每天如何更新

只修改 **`ledger.json`**。在 GitHub 打开这个文件，点铅笔编辑，保存提交即可。GitHub Pages 会自动重新发布，朋友刷新页面就能看到。

`returns` 中的数字单位是 **元**：盈利正数、亏损负数、无盈亏填 `0`、尚未录入填 `null`。

例如在对应月份的 `days` 数组中添加下面这一项（仅示例，不是真实战绩）：

```json
{
  "date": "2026-09-07",
  "returns": { "伦": 1200, "镭": -800, "健": 260, "超": 0 }
}
```

多天之间用英文逗号分隔；同一天只能出现一次。四人都要有名字和数值，未录入使用 `null`。

## 新增月份

在 `months` 中复制一份月份结构，改月份名、清空 `days`，本金沿用上月或填写新本金。每个月明确保存自己的本金，修改某月不会改变其他月份。

```json
"2026-10": {
  "capitals": { "伦": 200000, "镭": 600000, "健": 20000, "超": 150000 },
  "days": []
}
```

初始本金：伦 20 万、镭 60 万、健 2 万、超 15 万。

## 统计规则

- 金额和收益率按钮同时切换冠军、排名、图表和明细。
- 每日收益率 = 当日盈亏 ÷ 当月固定本金 × 100%。
- 月累计收益率 = 当月盈亏合计 ÷ 当月固定本金 × 100%，不使用复利。
- 四人录齐才评每日冠军；并列共同获胜；全亏取亏损最少者。
- 未录入不算零收益，也不参与无记录成员的月度排名。

## GitHub Pages 发布

仓库 Settings → Pages → Source 选择 **GitHub Actions**。提交 `ledger.json` 后，发布流程校验数据、解压 `site.zip`，再将最新数据放入网页。

网页入口预计为 `https://arreylalala.github.io/wall-street-wolves/`（须仓库创建和 Pages 发布成功后才可访问）。

`site.zip` 已包含构建完成的网页；`source.zip` 保存完整可编辑源码。日常修改数据无需手动安装依赖或运行构建。

GitHub Pages 是境外托管，中国大陆不同地区与运营商的可用性可能不同；不保证稳定可达。

## 修改界面

先解压 source.zip，使用 Node.js 22.13+ 和 pnpm，安装依赖后：

```sh
pnpm dev
pnpm test
pnpm build
```

`pnpm build` 会校验数据并更新 `docs/` 中的静态页面，同时保留 `docs/data/ledger.json`。修改界面后，将 docs 目录内的全部内容重新打包为 site.zip 并更新 source.zip；只修改仓库根目录 ledger.json 则不需要重新构建。

源码：`app/dashboard.tsx`、`app/globals.css`；计算：`lib/ledger.ts`；文件校验：`lib/data.ts`。
